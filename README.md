# Citizen Science Platform

A medication tapering tracker where users log their taper schedule and, optionally,
donate that data for research. Users can participate as a guest or create an account
to keep a history of past uploads on their profile.

Built with [Next.js](https://nextjs.org) (App Router) + TypeScript + Tailwind CSS.

Currently in progress: static HTML/CSS pages first (landing, login/signup, upload,
profile), with the account system, file storage, and LLM-based processing pipeline
to follow.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.
